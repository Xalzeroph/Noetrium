# Research catalog

`agent_reproduction_scope.json` is the exhaustive discovery boundary. It answers: what kinds of agent research must never be silently excluded?

`research_program.json` is the canonical reproduction program. It answers: which methods/benchmarks/gaps/innovation tracks have been promoted into executable research work, and what is their current status?

The discovery scope is intentionally broader than the active program. `scripts/validate_agent_reproduction_scope.py` reports discovered seed lineages that have not yet been promoted, so priority can change execution order without shrinking scope.

No catalog is a runtime service. External repositories remain references only. Method-specific science belongs to reproduction/downstream code; only reusable mechanisms justified by multiple real reproductions are promoted to Noetrium Platform systems.
