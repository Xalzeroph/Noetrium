# Noetrium Community Code of Conduct

Noetrium is an open-source research infrastructure project. We want technical disagreement to be rigorous, evidence-based, and respectful.

## Expected behavior

Community members should:

- discuss ideas, code, experiments, and evidence rather than attacking people;
- give actionable technical feedback and distinguish facts from hypotheses;
- welcome contributors with different experience levels and backgrounds;
- respect privacy, security boundaries, and coordinated disclosure;
- acknowledge prior work and avoid misrepresenting another contributor's results;
- keep research claims proportional to the evidence actually available.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, sexualized attention, doxxing, deliberate intimidation, sustained personal attacks, or knowingly publishing another person's private information are not acceptable.

Technical misconduct also includes deliberately falsifying test or research evidence, concealing material conflicts in a review, or using project channels to pressure others into accepting unsupported claims.

## Scope

This code applies in Noetrium repositories, issues, pull requests, Discussions, review channels, and other spaces where someone is acting as a project participant or representative.

## Reporting conduct problems

Use GitHub moderation and reporting tools where available. If a conduct report contains security-sensitive information, use the private security path described in `SECURITY.md` rather than a public issue.

Maintainers may edit or remove content, close or lock threads, reject contributions, or restrict participation when necessary to protect the project and its community. Enforcement decisions should be based on documented behavior and should avoid exposing unrelated private information.

## Research and review culture

Strong disagreement is welcome when it improves the system. Reviewers are encouraged to ask for exact revisions, reproducible evidence, failure cases, and explicit assumptions. Contributors should be able to revise or withdraw a claim without being personally attacked for doing so.
