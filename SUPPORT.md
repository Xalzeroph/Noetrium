# Support

Use the channel that matches the kind of help you need.

## Questions and design discussion

Use [GitHub Discussions](https://github.com/Xalzeroph/noetrium/discussions) for setup questions, architecture discussion, research integration ideas, and open-ended design topics.

## Bugs

Use the Bug Report issue form when you can describe a reproducible defect. Include the Noetrium version or exact commit and enough environment information to distinguish a platform defect from a downstream integration problem.

## Feature proposals

Use the Feature Request issue form for scoped capabilities with a concrete user or research need. Broader ideas should begin in Discussions before becoming implementation work.

## Security

Follow `SECURITY.md`. Never place vulnerability details in a public support thread or issue.

## Project-specific research help

Noetrium keeps project-specific scientific methods, benchmark policy, experiment matrices, and result interpretation downstream. Questions about a downstream research repository should normally be handled by that project's own support channels.
